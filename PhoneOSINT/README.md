# Phone OSINT Tool

A Python-based tool for phone number metadata analysis and generating public search links.

## Features
- Phone number validation
- Country information
- Carrier metadata
- Timezone information
- Public social media search links
- JSON report generation

## Important Limitations
- Does not provide live GPS location.
- Does not access private social media accounts.
- Does not confirm social media account ownership.
- Public search links do not guarantee results.
- Carrier information may be outdated.

## Privacy and Responsible Use
Use only phone numbers that you own or are authorized to analyze.

This project is intended for educational and authorized OSINT research.

## Technology
- Python
- phonenumbers
- JSON
- Public search engines
