

\# Phone OSINT Tool



Version: 3.0



An authorized public metadata analysis tool built with Python.



\## Features



\- International phone number validation

\- Country and numbering metadata

\- Carrier metadata

\- Timezone information

\- Public search engine links

\- Social media public search links

\- JSON investigation reports



\## Requirements



\- Python 3.14

\- phonenumbers



\## Installation



```bash

python -m pip install -r requirements.txt

```



\## Run



```bash

python main.py

```



\## Validation



```bash

python -m py\_compile main.py config.py public\_search.py phone\_osint.py

python -m pip check

```



\## Important Limitations



\- No live GPS tracking.

\- No private social media access.

\- Phone validation does not identify ownership.

\- Carrier metadata may be outdated.

\- Search links do not confirm account ownership.



Use only your own or explicitly authorized phone numbers.
